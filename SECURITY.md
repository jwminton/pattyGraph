# Security Policy

## Reporting a Vulnerability

If you find a security issue in PattyGraph, please do not open a public GitHub issue with exploit details.

Instead, report it privately by contacting the maintainer.

Include:

- a short description of the issue
- steps to reproduce, if possible
- affected version or commit
- any relevant logs or example input

I will review reports as time allows and publish fixes or mitigations when appropriate.

## Scope

PattyGraph is a local terminal tool for analyzing nginx-style access logs. Reports are most useful when they relate to:

- unsafe parsing behavior
- crashes caused by malformed log input
- startup/runtime configutation interpretation 
- build or dependency issues

## Supported Versions

The latest public release is the supported version.
